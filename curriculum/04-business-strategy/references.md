## Strateji Araclari ve Modeller (Ozet)

| Model / Cerceve | Birincil Kullanim | Kaynak |
|----------------|-------------------|--------|
| Porter 5 Guv | Sektor analizi, karlilik tahmini | Porter (1980) |
| Generic Strategies | Rekabet konumlandirma | Porter (1980) |
| Value Chain | Ic analiz, maliyet/farklilastirma | Porter (1985) |
| Strategic Group Map | Rekabet haritasi, stratejik setler | Porter / McGee-Thomas |
| Strategy Canvas | Sektorun stratejik profilini gorsellestirme | Kim & Mauborgne (2005) |
| ERRC Matrix | Deger inovasyonu icin eylem cercevesi | Kim & Mauborgne (2005) |
| Business Model Canvas | Is modeli haritalama | Osterwalder & Pigneur (2010) |
| Value Proposition Canvas | Musteri deger onerisi dogrulama | Osterwalder vd. (2014) |
| Ansoff Matrix | Buyume yonu secimi | Ansoff (1957) |
| BCG Matrix | Portfoy yonetimi, kaynak onceliklendirme | BCG (1970) |
| OKR | Hedef belirleme ve strateji izleme | Doerr (2018) |
| MECE / Issue Tree | Problem yapisi, hipotez testi | McKinsey / Minto |
| NPS | Musteri bagliligi olcumu | Bain / Reichheld |
| Disruptive Innovation | Pazar yikimi analizi | Christensen (1997) |
| Jobs to Be Done | Musteri motivasyonu analizi | Christensen vd. (2016) |
| SCCT | Kriz iletisim stratejisi | Coombs (2014) |
| First Principles | Varsayimlari sifirlama, inovasyon | Aristotle / Musk |
